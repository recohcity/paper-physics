# Trebuchet

Interactive 3D counterweight trebuchet — lever physics, energy conversion, projectile flight, block knockdown.

## 实现的物理特性

### 杠杆与配重
- 4:1 杠杆比：长臂 0.62 m，短臂 0.17 m
- 配重箱悬挂在短臂端（pin_x = 0.155 m），自由摆动
- 释放角 -90°（垂直位置），球在杯口水平离开
- 拉角范围 0°–135°（45° 越过立柱），能量随角度增加

### 刚体物理（cannon-es）
- 重力 g = 9.82 m/s²
- 80 迭代求解器，容差 1e-7，绳索链稳定
- 接触材质：木-木摩擦 0.35 / 恢复 0.15，金-木摩擦 0.4 / 恢复 0.1
- 绳索由多段 PointToPoint 约束小球链模拟
- 球离杯后受完整抛体运动（无空气阻力）
- 速度与角度从物理状态实时读出（v = ω × r），非拟合公式

### 参数化实验
| 参数 | 范围 | 默认 | 效果 |
|---|---|---|---|
| 配重 | 1.4–10 kg | 4.8 kg | ≥4.8 kg 可推倒第 3 层积木；<1.4 kg 释放后不倒转 |
| 球重 | 0.30–0.60 kg | 0.45 kg | 球比配重重时变成跷跷板，杯口向下停住 |
| 拉角 | 0°–135° | 0° | 拉得越高，配重势能越大 |

### 能量转换
- 配重下落势能 → 杠杆角速度 → 球端线速度
- 4:1 杠杆把短臂端速度放大 4 倍到杯端
- 实时记录离杯速度、发射角、飞行距离、命中动量

### 积木击倒
- 5 块木积木堆叠成金字塔
- 球以动量撞击：动能足够则击倒，不足则只推倒前方
- 积木间摩擦 0.35：被撞块倒下时仍抓住邻块

## 交互

### Tour
8 步自动演示：铅笔草图 → 轮廓凸起 → 2D 展开 → 3D 白模 → 上材质 → 物理公式 → 发射 → 0.25× 慢动作回放（显示飞行轨迹）。

### Build
- 拖动滑块：配重质量、球重、拉角
- 拖动杯子上弦（或拉角滑块）
- 点 Fire 发射
- 飞行轨迹开关：实时记录抛体路径
- Slow Motion：0.25× 回放
- Reset：球回架上，积木复位
